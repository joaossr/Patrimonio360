# Patrimônio 360 — Backend

## v40 — IA Contextual

Esta versão corrige a memória contextual da IA e amplia as análises de compras, parcelamentos, categorias, orçamento, reserva, cartões e compromissos.

### Importante
Depois de substituir a pasta, reinicie completamente o backend. Se `http://localhost:8787/health` estiver mostrando a versão antiga, você ainda está acessando o processo anterior.

Mantenha o `service-account.json` nesta pasta e confira o `.env`.
